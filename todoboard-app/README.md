# TodoBoard App

A todo.txt task management application with Kanban-style board interface.

## Getting Started

### Prerequisites

- Node.js 22+
- Yarn 4.x

### Development Setup

1. **Install dependencies**

   ```bash
   yarn install
   ```

2. **Start development server**

   ```bash
   yarn dev
   ```

3. **Open in browser**
   ```
   http://localhost:5173
   ```

### Available Scripts

- `yarn dev` - Start development server
- `yarn build` - Build for production
- `yarn preview` - Preview production build
- `yarn format` - Format code with Prettier
- `yarn format:check` - Check code formatting

### Technology Stack

- Vue.js 3 + TypeScript
- Bootstrap 5
- Vite
- todo-txt-ts parser
- Prettier (tabs for JS/TS)
